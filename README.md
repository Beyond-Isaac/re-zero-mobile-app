##  Telas Implementadas
* **Welcome:** Tela de boas-vindas com fundo estilizado.
* **Sign-in (Login):** Acesso à conta com e-mail e senha.
* **Sign-up (Cadastro):** Criação de nova conta.
* **Forgot Password:** Recuperação de senha por e-mail.

## Tecnologias Utilizadas
* **React Native**
* **Expo**
* **Expo Linear Gradient**
* **JavaScript**
